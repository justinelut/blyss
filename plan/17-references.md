# Appendix A — Visual Bible

> See also: [04-ui-direction.md](./04-ui-direction.md) §3.1 (the short reference list); this appendix expands it

This is the anti-AI-slop reference set. Before any new page or component is drafted, the AI agent visits the relevant tiers below, screenshots the hero and one inner page, and references those compositions when laying out Blyss.

The discipline: ask, every time, *"Does this look like it could exist on Are.na or Aimé Leon Dore? Or does it look like a Shopify template?"* If the latter, scrap and rebuild.

---

## Tier 1 — Primary aesthetic anchors (the visual ceiling)

These ARE the standard. Copy the discipline, copy nothing literally.

| Site | What to study |
|---|---|
| https://www.are.na | Editorial confidence, type-driven layouts, no decoration. PRIMARY peer for Blyss's brand voice. Study the homepage's spatial rhythm, the typography hierarchy, the absolute restraint with color. |
| https://aimeleondore.com | Premium product gallery treatment. Each product image is given gallery-grade space. Note the way they let photos breathe — minimal copy on product pages, big imagery, tight type. |
| https://www.ssense.com | The single best filter and search UX in commerce. Study the filter sidebar, the way active filters render as removable chips, the persistent URL state across navigation. |
| https://shop.highsnobiety.com | Editorial commerce hybrid. Long-form drop stories that double as product pages. Note how content density never tips into clutter. |
| https://www.mrporter.com | Content + commerce hybrid done at world-class scale. Study the editorial PDPs (product detail pages) — the way a t-shirt gets a magazine layout. |
| https://www.dovermarket.com | Minimalist gallery commerce. The closest peer to Blyss's restraint ambition. Note how they use type as the entire visual system. |
| https://stripe.com | Not commerce, but the visual ceiling for fintech UI density. Study the type hierarchy, the way they use color as accent (the Stripe gradient excepted — we don't use gradients), the spatial rhythm. |
| https://linear.app | The cleanest application UI on the internet. Type system, motion tone, density, restraint. The dashboard reference. |
| https://casadisolare.com | Awwwards Site of the Month, score 9.30. Reference for hero compositions in 2026 commerce design. |
| https://airscream.com | Awwwards Site of the Month for ecommerce, 8.80 score. Modern editorial commerce. |
| https://heyday.is | Newer editorial commerce reference. |
| https://www.everpress.com | Creator-first commerce platform with strong editorial voice. |

**Specific lessons by surface:**

- **Hero:** Are.na, Aimé Leon Dore, Casa di Solare

- **PDP (product detail):** Mr Porter, Highsnobiety Shop, Dover Market

## Tier 7 — ANTI-REFERENCES (study, copy nothing)

These exemplify what generic ecommerce sites look like. Blyss must outclass them on every dimension.

- **Generic Shopify "marketplace" themes** — search "shopify marketplace theme" on Google Images for what to avoid. They all look the same: gradient hero, hard-edged neon CTAs, "Shop now" buttons everywhere, Trustpilot widgets, three-column "Why us" sections.
- **Generic Wix/Squarespace ecommerce templates** — same energy.
- **Bootstrap-themed marketplaces** — owl-carousels with hover-zoom on every product, "Featured Products" carousels, badge spam.
- https://www.etsy.com — outdated, packed with shouts and stars and badges. Looks like 2016. Reference for what the discount-marketplace look feels like; reference for what to NOT do.
- https://www.aliexpress.com — busy, overwhelming, low-trust.
- https://www.ebay.com — auction-marketplace UI, dense and dated.
- Jumia, Kilimall, Konga (mentioned in Tier 4 anti-refs).
- AI-generated ecommerce sites with three-column emoji feature grids, animated counters, "Trusted by 1,500 brands" trust strips, and gradient hero overlays.

## How to use this Visual Bible

Before drafting any new page or component:

1. Open Are.na, Aimé Leon Dore, Casa di Solare, Cereal Magazine, and Linear in tabs.
2. Identify the composition technique you're about to use.
3. Find a peer that solves it well in Tier 1 or Tier 2.
4. Match the spacing rhythm, type scale, photography treatment, and motion tone.
5. Run the §3.5 anti-pattern checklist.
6. Run the §15 do-not-do list.
7. If the draft could plausibly live on Are.na or Aimé Leon Dore, ship.
8. If it could plausibly live on Etsy or Jumia, scrap and rebuild.

The Visual Bible is a teacher, not a copy source. Internalize the language, then write code.
